    여러 노트북에서 순위 공유하기

    지금은 로컬 모드입니다

    현재 순위는 이 브라우저에만 저장됩니다. 팀별 노트북에서 순위를 실시간으로 함께 보려면 Firebase Realtime Database를 연결하세요. (무료, 5분)

    ⚠️ 로컬 모드에서는 노트북마다 다른 인물 16명이 나올 수 있어 팀 간 공정한 대결이 어렵습니다. 여러 노트북으로 진행할 때는 꼭 Firebase를 연결해 주세요.

    1. Firebase 콘솔에서 새 프로젝트를 만들고 Realtime Database를 생성합니다.
    2. 데이터베이스 규칙을 테스트용으로 열어 둡니다. { "rules": { ".read": true, ".write": true } }
    3. 프로젝트 설정 → 내 앱(웹)에서 firebaseConfig 값을 복사합니다.
    4. js/config.js의 firebase: 항목에 붙여넣고 다시 배포합니다.

    자세한 설명은 README.md에 있습니다.
