# 🎮 연예인 같은그림찾기 서바이벌

워크샵용 팀 대항 기억력 게임입니다. 32장 카드 속 16명의 인물 중 **같은 인물 두 장**을 찾아야 하고,
**한 번이라도 다른 인물이 나오면 즉시 탈락**합니다. 16쌍을 모두 맞히고 `완료` 버튼을 누른 순서대로 1·2·3등이 정해집니다.

- 정적 HTML/CSS/JS — GitHub Pages, Netlify, 사내 웹서버 어디든 폴더만 올리면 동작합니다.
- 팀별 노트북(가로 화면)에서는 **8열 × 4행**으로 32장이 스크롤 없이 한눈에 들어오고, 휴대폰에서는 **4열 × 8행**으로 자동 전환됩니다.
- 매 라운드 인물 후보 36명 중 **16명을 무작위로 새로 뽑아** 진행합니다. 같은 라운드의 모든 팀은 동일한 16명으로 공정하게 겨룹니다.

---

## 1. 게임 규칙

| 항목 | 내용 |
|---|---|
| 카드 | 32장 = 16쌍 (한 화면에 8×4 / 모바일 4×8) |
| 미리보기 | 시작 시 32장이 물결처럼 순차로 뒤집혀 4~5초간 공개된 뒤 모두 덮입니다. (남은 시간 카운트다운 표시, 관리자 화면에서 4·5·7·10·15초로 변경 가능) |
| 진행 | 카드 두 장을 뒤집어 같은 인물이면 그대로 열린 상태로 유지 |
| 탈락 | 두 장이 다른 인물이면 **즉시 탈락** (기회 1회). 게임 종료 |
| 잠금 | 탈락·완료 후에는 새로고침해도 재도전 불가 (localStorage 잠금). 사회자가 초기화해야 다시 참여 |
| 완료 | 16쌍을 모두 맞히면 하단 `완료` 버튼이 활성화 → 누른 순서(서버 타임스탬프)로 순위 결정 |
| 순위 표시 | 참가자 화면에 내 순위(1·2·3등 또는 완료 n번째) 표시 |

## 2. 파일 구조

```
workshop-memory-game/
├─ index.html          참가자 화면
├─ admin.html          사회자(운영) 화면 — 링크 복사 / QR / 리더보드 / 라운드 관리
├─ css/
│  ├─ style.css        게임 화면 스타일 (데스크톱 8×4 · 모바일 4×8, 3D 플립)
│  └─ admin.css        운영 화면 스타일
├─ js/
│  ├─ config.js        ★ 인물 후보 목록 + Firebase 설정 (여기만 고치면 됩니다)
│  ├─ store.js         저장소 계층 (Firebase ↔ localStorage 자동 전환, 라운드 추첨)
│  ├─ game.js          게임 로직 (미리보기 웨이브, 매칭, 탈락, 잠금, 순위)
│  └─ admin.js         운영 화면 로직
├─ images/
│  ├─ celeb_01.jpg ~ celeb_36.jpg   인물 사진 36명 (512×512)
│  └─ CREDITS.md       사진 출처·라이선스
└─ README.md
```

## 3. 로컬에서 바로 확인하기

```bash
cd workshop-memory-game
python3 -m http.server 8000
# 참가자: http://localhost:8000/index.html
# 사회자: http://localhost:8000/admin.html
```

> `index.html`을 파일로 직접 열어도 게임은 동작하지만, Firebase·클립보드 기능은 http(s) 환경에서 가장 안정적입니다.

## 4. 배포 (GitHub Pages)

1. 새 저장소를 만들고 `workshop-memory-game` 폴더 **안의 내용물**을 그대로 올립니다.
2. 저장소 `Settings → Pages → Source: Deploy from a branch → main / (root)` 를 선택합니다.
3. 잠시 후 `https://<아이디>.github.io/<저장소>/index.html` 로 접속됩니다.
4. 사회자 화면은 `.../admin.html` 입니다.

> 폴더째 올리면 주소가 `.../<저장소>/workshop-memory-game/index.html` 이 됩니다. 어느 쪽이든 `admin.html`이 같은 위치에 있으면 링크가 자동으로 맞춰집니다.

## 5. Firebase 연결하기 (여러 노트북에서 순위 공유)

**연결하지 않아도 게임은 100% 동작합니다.** 다만 그때는 순위가 그 노트북(브라우저) 안에만 기록되므로,
팀별 노트북으로 진행하려면 아래 5분 설정을 권장합니다.

1. <https://console.firebase.google.com/> → **프로젝트 추가** (이름 예: `workshop-game`).
2. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기** → 위치 선택 → **테스트 모드**로 시작.
3. `규칙(Rules)` 탭을 아래처럼 설정 후 게시:

   ```json
   { "rules": { ".read": true, ".write": true } }
   ```

   > 워크샵 당일만 열어 두고, 끝나면 규칙을 닫거나 데이터베이스를 삭제하세요.

4. 프로젝트 설정(⚙️) → **내 앱 → 웹 앱 추가** → 표시되는 `firebaseConfig` 값을 복사.
5. `js/config.js` 의 아래 부분을 채우고 다시 배포합니다.

   ```js
   firebase: {
     apiKey: "AIza...",
     authDomain: "workshop-game.firebaseapp.com",
     databaseURL: "https://workshop-game-default-rtdb.asia-southeast1.firebasedatabase.app",
     projectId: "workshop-game",
     storageBucket: "workshop-game.appspot.com",
     messagingSenderId: "000000000000",
     appId: "1:000000000000:web:xxxxxxxx"
   }
   ```

6. `admin.html` 상단 배지가 **실시간 공유 중**으로 바뀌면 성공입니다.

데이터 구조(참고):

```
session/   { gameId, roundNo, previewSeconds, roundIds:[16개], resetAt }
teams/     { <pushKey>: { name, gameId, status: playing|done|out, startedAt, completedAt, failedAt, pairs, elapsedMs } }
```

순위는 `status: done` 팀을 `completedAt`(Firebase 서버 시각) 오름차순으로 정렬해 계산합니다.

## 6. 당일 운영 순서

1. 노트북에서 `admin.html` 을 엽니다.
2. **참가자 접속 링크**를 `링크 복사` 로 복사해 단체 채팅방·메일로 공유합니다. (필요하면 `QR 코드로 접속` 을 펼쳐 화면에 띄워도 됩니다.)
3. 각 팀은 링크에 접속 → 팀 이름 입력 → `게임 시작`.
4. 리더보드에서 완료/탈락/진행 중 현황이 실시간으로 갱신됩니다. 1~3등은 금·은·동으로 강조됩니다.
5. 다음 판을 하려면 **`새 라운드 시작 (초기화)`** → 확인. 인물 16명이 새로 뽑히고, 모든 팀의 잠금이 풀립니다.
6. 필요하면 `미리보기 시간`을 4·5·7·10·15초 중에서 조절합니다. (변경 즉시 모든 팀에 적용)

## 7. 화면 크기별 동작

| 화면 | 카드 배치 | 특징 |
|---|---|---|
| 데스크톱·노트북 (가로, 821px 이상) | **8열 × 4행** | 스크롤 없이 한 화면, 카드는 화면 높이에 맞춰 자동 크기 조정, 마우스 호버 시 카드가 살짝 떠오르고 테두리가 밝아짐 |
| 태블릿·휴대폰 (820px 이하) | **4열 × 8행** | 한 손 조작, 완료 버튼은 하단 전체 폭 |

카드 크기는 `game.js` 의 `layoutBoard()` 가 화면 영역을 실측해 매번 계산하므로, 창 크기를 바꿔도 스크롤이 생기지 않습니다.

## 8. 문제 해결

| 증상 | 확인 |
|---|---|
| 순위가 다른 노트북에 안 보임 | 아직 **로컬 모드**입니다. `js/config.js` 의 `firebase` 값을 채우세요. |
| 팀이 "이미 참여한 팀" 으로 잠김 | 사양상 정상입니다. `admin.html` → `새 라운드 시작 (초기화)` 로 풀립니다. |
| 사진이 안 보임 | `images/celeb_NN.jpg` 파일명과 `config.js` 의 `id` 가 일치하는지 확인하세요. |
| 소리가 안 남 | 브라우저 자동재생 정책상 첫 클릭 이후부터 재생됩니다. 우상단 🔊 버튼으로 끄고 켤 수 있습니다. |
| 완료 버튼이 안 눌림 | 16쌍을 모두 맞혀야 활성화됩니다. |
